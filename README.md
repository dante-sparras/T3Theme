# T3 Theme

A Visual Studio theme pack inspired by T3 Chat.

## Building from Source

### Prerequisites

- Visual Studio 2022/2026 + VSIX development tools
- .NET Framework 4.7.2

### Build Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/dante-sparras/T3Theme.git
   cd T3Theme
   ```

2. Open the solution:

   ```bash
   T3Theme.slnx
   ```

3. Build the solution in Visual Studio (Ctrl+Shift+B)

4. The `.vsix` file will be generated in `src\bin\Debug\` or `src\bin\Release\`
